# Japan Recon Car Gallery — Interactive Demo

A static, local prototype for an interactive Japanese recon-car gallery.

## Important demo boundary

- Every vehicle, mileage figure and specification is fictional demonstration data.
- The prototype does not submit real enquiries, reservations or payments.
- No backend/database is used in this version.

## Run locally

```bash
cd japan-recon-car-gallery
python -m http.server 8080
```

Then open http://127.0.0.1:8080/
